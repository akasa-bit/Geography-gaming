# 自然地理シミュレーター

受験地理(自然地理)の学習用アプリ兼クイズゲーム。実在の地球の観測データを、経度1°×緯度1°(360×180)の格子で表示・出題する。ブラウザだけで動く(`index.html` を開く。ビルド不要)。

## 使い方

1. **地形・プレート** — 地図を 地形/大地形(安定陸塊・古期造山帯・新期造山帯)/プレート/マントル に切り替えて、プレート境界と大地形の関係を見る。
2. **気候を読む** — 気温・降水量(年間と各月)・ケッペンの気候区分・植生の地図を見る。海流と風の矢印も重ねられる。地点をタップすると雨温図・ハイサーグラフ・判定手順・その気候になる理由が出る。
3. **気候判定クイズ** — ゲームが選んだ地点の雨温図とハイサーグラフを読み、気候区分(40点)・植生(20点)・土壌(10点)・農業形態(15点、3つまで)・作物/家畜(15点、3つまで)を答えて採点。苦手な気候区分は出題されやすくなる。解答は1問ごとに記録され(ブラウザの localStorage)、50問ごとに傾向分析(項目別得点率・取り違えの組み合わせ・間違いの原因・南北半球別・次にやること)が出る。「記録・分析」ボタンでいつでも途中経過と間違えた問題の一覧を見られる。

## データ

政府機関・大学のデータを1°×1°に集計したもの(`data/earth.js`、gzip圧縮で約2.8MB)。

- 標高・水深: NOAA NCEI ETOPO 2022
- 陸上の気温・降水量: デラウェア大学 v5.01(NOAA PSL 提供、1981〜2010年平均)
- 海面水温: NOAA OI SST V2 / 海上の降水量: GPCP v2.3 / 風: NCEP/NCAR 再解析 / 海流: NOAA GODAS(いずれも1991〜2020年平均)
- プレート: Bird (2003) PB2002

出典・URL・加工方法の詳細は `data/SOURCES.md`。`python3 tools/build_earth_data.py <データを置いたフォルダ>` で再生成できる。

データそのものではなく、このアプリで作っているもの:

- **ケッペンの気候区分・植生の地図** — 上の気温・降水量から教科書の判定法(乾燥限界 r=20(t+x)、x は夏雨型14・年中7・冬雨型0)で計算。標高2000m以上は高山気候(H)。植生は気候区分からの対応。
- **大地形の区分** — 教科書に載る主な造山帯の位置を手で指定。
- **マントルの流れ** — プレート境界(広がる境界=上昇流、狭まる境界=下降流)からの推定。
- **「なぜこの気候になるか」の因子の説明** — 緯度・気圧帯の季節移動・隔海度・海流・季節風・地形を数式にした簡略モデル(`js/climate.js` の `simulate`)による推定。気温・降水量の値には使っていない。`node tools/calibrate.js` でこのモデルと観測の一致度を確認できる(区分の一致56.6%、大区分82.5%)。

## ファイル

- `data/earth.js` 実在の地球のデータ(生成物) / `data/SOURCES.md` 出典
- `tools/build_earth_data.py` データの集計スクリプト
- `js/core.js` 格子・プレート境界・大地形
- `js/climate.js` ケッペン判定、観測データの適用、因子説明用の簡略モデル
- `js/knowledge.js` 気候区分・植生・土壌・農業・作物の対応と解説
- `js/charts.js` 雨温図・ハイサーグラフ
- `js/review.js` 解答記録と傾向分析
- `js/app.js` 画面(地図描画・クイズ)
