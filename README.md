# 自然地理シミュレーター

受験地理(自然地理)の学習用アプリ兼クイズゲーム。実在の地球のデータだけを、経度1°×緯度1°(360×180)の格子で表示・出題する。シミュレーションは使わない。ブラウザだけで動く(`index.html` を開く。ビルド不要)。

## 使い方

1. **地形・プレート** — 地図を 地形/大地形(安定陸塊・古期造山帯・新期造山帯)/プレート に切り替えて、プレート境界と大地形の関係を見る。
2. **気候を読む** — 気温・降水量(年間と各月)・ケッペンの気候区分・植生・農業(作物ごとの収穫面積、家畜の密度)の地図を見る。海流と風の矢印も重ねられる。地点をタップするとピンが立ち、雨温図・ハイサーグラフ・判定手順・その地点の植生/作物/家畜/大地形のデータが出る。
3. **気候判定クイズ** — ゲームが選んだ地点の雨温図とハイサーグラフを読み、気候区分(40点)・植生(20点)・農業形態(15点)・作物/家畜(25点、3つまで)を答えて採点。正解はすべてその地点のデータ。苦手な気候区分は出題されやすくなる。解答は1問ごとに記録され(ブラウザの localStorage)、50問ごとに傾向分析が出る。形式は2つ。「グラフから判定」は上のとおり。「白地図の地点から判定」は、白地図上のランダムな陸上の点(面積に比例して選ぶ)にピンが立ち、位置だけを手がかりに標高(0〜50m/50〜500m/500〜1000m/1000〜2000m/2000m〜、15点)・気候区分(35点)・植生(20点)・農業形態(10点)・作物/家畜(20点)を答える。

## データ

政府機関・大学などの公開データを1°×1°に集計したもの(`data/earth.js`、gzip圧縮で約3MB)。

| 内容 | データ |
| --- | --- |
| 標高・水深 | NOAA NCEI ETOPO 2022 |
| 陸上の気温・降水量 | デラウェア大学 v5.01(NOAA PSL 提供、1981〜2010年平均) |
| 海面水温 / 海上の降水量 / 風 / 海流 | NOAA OI SST V2 / GPCP v2.3 / NCEP/NCAR 再解析 / NOAA GODAS(1991〜2020年平均) |
| プレート | Bird (2003) PB2002 |
| 大地形 | Hasterok et al. (2022) Global geologic provinces |
| 植生 | ウィスコンシン大学 SAGE Global Potential Vegetation(Ramankutty & Foley 1999) |
| 作物 | MapSPAM 2020 V2r2 収穫面積(IFPRI、46作物を36区分に集約)。オリーブと飼料作物は GAEZ+ 2015 |
| 家畜 | FAO Gridded Livestock of the World 2015 |
| 家畜生産システム | FAO/ILRI Global livestock production systems v5 |
| 農業地域区分 | ホイットルセー(1936)の区分図の画像を1°格子に読み取ったもの(14区分)。クイズの農業形態の正解 |
| 現在の農業区分 | 上の作物・家畜・灌漑・気候のデータに規則をあてはめた自作の区分(13の型)。データセットではない。地図で見比べる用 |

出典・URL・加工方法・クイズのしきい値は `data/SOURCES.md`。`python3 tools/build_earth_data.py <データを置いたフォルダ>` で再生成できる。

ケッペンの気候区分は、観測の気温・降水量を教科書の判定法(乾燥限界 r=20(t+x)、x は夏雨型14・年中7・冬雨型0)にあてはめたもの。標高2000m以上は高山気候(H)。解説の「教科書の知識」欄(気候区分ごとの農業・土壌の一般論)だけはデータではなく文章。

## ファイル

- `data/earth.js` 地球のデータ(生成物) / `data/SOURCES.md` 出典 / `data/whittlesey.jpg` 農業地域区分の元の地図(利用者提供、出典未確認)
- `tools/build_earth_data.py` データの集計スクリプト
- `js/core.js` 格子・データの展開・プレート境界
- `js/climate.js` ケッペン判定と表示用データの組み立て
- `js/knowledge.js` 名称・色・教科書の解説文
- `js/charts.js` 雨温図・ハイサーグラフ
- `js/review.js` 解答記録と傾向分析
- `js/app.js` 画面(地図描画・クイズ)
