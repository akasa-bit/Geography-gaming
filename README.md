# 自然地理シミュレーター

受験地理(自然地理)の学習用シミュレーター兼クイズゲーム。ブラウザだけで動きます。

## 遊び方

`index.html` をブラウザで開く(ビルド不要)。

1. **地形・プレート** — 「地球(実データ)」「マントル対流から自動生成」「海だけの惑星」から始める。「地球(実データ)」は観測データをそのまま使い(下記)、地形を描き変えると自作の惑星になって気候はシミュレーションに切り替わる。自動生成はマントル対流 → プレート → 大地形の順に決まる(下記)。ブラシで陸地・山・海・プレートを手描きもでき、「マントルとプレートを自動で決める」で手描きの地形にプレートだけ割り当てることもできる。「造山運動を進める」と、狭まる境界に山脈・海溝・弧状列島、広がる境界に海嶺・地溝帯ができる。地図は 地形/大地形(安定陸塊・古期造山帯・新期造山帯)/プレート/マントル を切り替えられる。
2. **気候を読む** — 地形から海流・風・気温・降水量(12か月)を計算し、ケッペンの気候区分と植生の地図を描く。地点をタップすると雨温図・ハイサーグラフ・判定手順・その気候になる理由が出る。
3. **気候判定クイズ** — ゲームが選んだ地点の雨温図とハイサーグラフを読み、気候区分(40点)・植生(20点)・土壌(10点)・農業形態(15点、3つまで複数選択)・作物/家畜(15点、3つまで複数選択)を答えて採点。苦手な気候区分は出題されやすくなる。解答は1問ごとに記録され(`js/review.js`、ブラウザの localStorage)、50問ごとに傾向分析(項目別得点率・取り違えの組み合わせ・間違いの原因・南北半球別・次にやること)が出る。「記録・分析」ボタンでいつでも途中経過と間違えた問題の一覧を見られる。

## 地球(実データ)

実在の地球ではシミュレーションを使わず、政府機関・大学のデータを2°×2°に集計して表示・出題する(`data/earth.js`、約1.8MB)。

- 標高・水深: NOAA NCEI ETOPO 2022
- 陸上の気温・降水量: デラウェア大学 v5.01(NOAA PSL 提供、1981〜2010年平均)
- 海面水温: NOAA OI SST V2 / 海上の降水量: GPCP v2.3 / 風: NCEP/NCAR 再解析 / 海流: NOAA GODAS(いずれも1991〜2020年平均)
- プレート: Bird (2003) PB2002

出典・URL・加工方法の詳細は `data/SOURCES.md`。`python3 tools/build_earth_data.py <データを置いたフォルダ>` で再生成できる。ケッペンの区分と植生はこの気温・降水量から判定したもの、大地形の区分は手で指定したもの。

## 地形の自動生成(`js/core.js`)

1. **マントル対流** — なめらかな乱数場で上昇流と下降流を作る。表層の流れは上昇流から下降流へ向かう。
2. **プレート** — 「同じ上昇流から湧き、同じ下降流へ向かう範囲」を1枚のプレートとする。向きと速さはプレート直下のマントルの流れの平均。これで上昇流の上が広がる境界、下降流の上が狭まる境界になる。
3. **大地形** — 大陸地殻は広がる境界を避けて配置。海洋底は海嶺から離れるほど深く、大陸の縁に大陸棚。狭まる境界に海溝・弧状列島・大陸縁の山脈・大陸衝突の山脈(新期造山帯)、プレート内部に低くなだらかな古期造山帯、残りは安定陸塊。プレートの進行方向に並ぶホットスポットの火山島列も作る。

手描きや地球モデルでは、逆にプレート境界からマントルの流れを推定して表示する。

## シミュレーションの考え方

高校地理で学ぶ気候因子を1つずつ数式にした簡略モデル(`js/climate.js`)。

| 因子 | モデルでの扱い |
| --- | --- |
| 緯度 | 海面更正した年平均気温を緯度で与える |
| 気圧帯の季節移動 | 熱帯収束帯・亜熱帯高圧帯・亜寒帯低圧帯が夏半球側へ移動(陸上ほど大きい) |
| 風 | 貿易風・偏西風・極偏東風 + 大陸と海洋の比熱差による季節風 |
| 隔海度 | 風上へさかのぼって海までの距離を測り、年較差と水蒸気量に反映 |
| 海流 | 大洋西岸に暖流、東岸に寒流(亜熱帯循環)。高緯度の大洋東側は暖流 |
| 地形 | 気温の逓減 0.65℃/100m、風上の地形性降雨、風下の雨陰 |

ケッペンの区分は教科書の判定法(乾燥限界 r=20(t+x)、x は夏雨型14・年中7・冬雨型0)。標高2000m以上は高山気候(H)として扱う。

厳密な大気大循環モデルではないので、実際の地球とは一致しません。`node tools/calibrate.js` で、実在の地球の地形でシミュレーションした結果を観測データと陸セルごとに照合できます(現状: 区分の一致57.8%、A〜E・Hの大区分の一致82.7%、年平均気温の平均誤差3.5℃)。このモデルは自作・自動生成の惑星にだけ使います。

## ファイル

- `data/earth.js` 実在の地球のデータ(生成物) / `data/SOURCES.md` 出典
- `tools/build_earth_data.py` データの集計スクリプト
- `js/review.js` 解答記録と傾向分析
- `js/core.js` 地形・プレート・造山運動・ひな形
- `js/climate.js` 気候シミュレーションとケッペン判定
- `js/knowledge.js` 気候区分・植生・土壌・農業・作物の対応と解説
- `js/charts.js` 雨温図・ハイサーグラフ
- `js/app.js` 画面(地図描画・エディタ・クイズ)
